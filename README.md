# Aanvesha Static Web Portal

Responsive multi-page static website starter for the Aanvesha concept.

Pages: Home, For Schools, For Students, Programs, AI & Future, About, Contact, Resources.
Brand: AANVESHA
Tagline: Navigate Your Future. Shape Your Career.

Open index.html locally or run `python -m http.server 8000`.

Before launch: verify brand/trademark/domain availability; add founder/contact details; connect the contact form; review all admissions/career information; add privacy and terms pages as needed.

The package can be used as a normal static site or as a design/content master for recreating the experience in Google Sites.
